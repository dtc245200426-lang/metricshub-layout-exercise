# MetricsHub layout exercise

Bài gồm Navbar Flexbox, Dashboard CSS Grid với widget siblings và span, Pricing dùng Bootstrap 12 cột.

- Mở `index.html` để xem bản mã nguồn tiện truy cập tại repository.
- Tải `metricshub_submission.zip` để nộp đúng cấu trúc: thư mục metricshub_ui chứa index.html/style.css; layout_strategy.md; ai_prompt_log.md; audit.md.
- Audit có wireframe và câu trả lời vấn đáp. Nhật ký AI phản ánh đúng quá trình thực tế.
- Cần mạng để tải Bootstrap. Giá, dữ liệu và email example.com là minh họa.
